# DUFS Assets

This repository contains the static frontend assets for the `dufs` web interface.

## Included files

- `index.html` HTML template for browsing and editing files.
- `index.css` interface styles, including light and dark themes.
- `index.js` client-side logic for file listing, navigation, uploads, search, theme switching, and editing.
- `favicon.ico` application icon.

## Purpose

This directory provides the frontend resources used to display the filesystem structure and manage files through the browser.

## How to use

1. Copy or reference this directory as the assets directory for `dufs`.
2. Start the `dufs` server with the appropriate assets configuration.
3. Open the web interface in a browser and use the built-in features for browsing, uploading, deleting, and editing files.

## Main features

- browse directories and files;
- search by path or file name;
- upload files and folders;
- delete and move files;
- create new files and folders;
- view and edit text files;
- switch between light and dark themes.

## Note

This project does not include a separate build step. It is a static set of files intended to be used directly as `dufs` assets.
